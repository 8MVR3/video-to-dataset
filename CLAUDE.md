# video-to-dataset

Готовит видео к разметке: нарезает кадры с заданным шагом, убирает почти одинаковые, делит на train и val по видео и раскладывает кадры по архивам для разметчиков.

## Структура

- `video_to_dataset.py` — `extract` нарезает кадры и сравнивает каждый с предыдущим оставленным по dHash, `split_by_video` делит данные целыми видео, `make_batches` собирает архивы и распределяет их по разметчикам, `main` пишет `manifest.csv`, `train.txt` и `val.txt`.
- `tests/test_video_to_dataset.py` — генерирует три ролика (два с движением и один статичный) и проверяет весь конвейер.

## Команды

```
pip install -r requirements.txt
python video_to_dataset.py папка_с_видео out --every 1 --val 0.2 --batch 200 --labelers 4
pytest
```

## Правила

- Одно видео никогда не попадает и в train, и в val. Это главная гарантия инструмента.
- Кадры одного видео держатся рядом в архивах: так разметчику проще.
- Имена кадров содержат имя видео и номер кадра, по ним восстанавливается источник.
- Новые параметры добавлять с понятным значением по умолчанию, чтобы простой запуск работал без настроек.
